# Señales Preventivas

Esta carpeta contiene las imágenes de las 43 señales preventivas principales de Argentina.

## Características:
- Fondo: Amarillo
- Símbolos: Negros
- Forma: Romboidal o cuadrada
- Función: Advertir sobre riesgos y condiciones especiales

## Formato recomendado:
- Formato: PNG con fondo transparente
- Tamaño: 200x200px mínimo
- Calidad: Alta resolución
- Nomenclatura: preventiva-01.png, preventiva-02.png, etc.

## Ejemplos de señales preventivas:
- Curva peligrosa
- Calzada resbaladiza
- Cruce escolar
- Pendiente pronunciada
- Animales sueltos
- Intersección
- Puente angosto
- Obras en la vía
- Semáforo adelante
- Cruce ferroviario
- Y muchas más...

Las imágenes se irán agregando progresivamente para completar las 43 señales.
