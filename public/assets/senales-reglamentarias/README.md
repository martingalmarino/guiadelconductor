# Señales Reglamentarias

Esta carpeta contiene las imágenes de las señales reglamentarias de Argentina.

## Características:
- **Prohibiciones/Restricciones**: Forma circular, fondo blanco, borde rojo
- **Obligaciones**: Forma circular, fondo azul
- **Función**: Establecer prohibiciones, obligaciones o restricciones obligatorias

## Formato recomendado:
- Formato: PNG con fondo transparente
- Tamaño: 200x200px mínimo
- Calidad: Alta resolución
- Nomenclatura: descriptiva del contenido

## Tipos de señales reglamentarias:

### Prohibiciones (fondo blanco, borde rojo):
- Prohibido girar a la izquierda
- Prohibido girar a la derecha
- Prohibido girar en U
- Prohibido adelantar
- Prohibido estacionar
- Prohibido el paso
- Velocidad máxima
- Peso máximo
- Altura máxima
- Ancho máximo

### Obligaciones (fondo azul):
- Sentido único
- Uso obligatorio de cinturón
- Uso obligatorio de casco
- Dirección obligatoria
- Carril exclusivo
- Velocidad mínima

### Restricciones especiales:
- Solo buses
- Solo taxis
- Solo bicicletas
- Solo peatones
- Horarios específicos
